title: Chat Products with Tools
---
Not a place for general chat assistants. Do not add ChatGPT, Claude, Gemini, or Microsoft Copilot here, even when they have connectors, computer use, or a cowork mode. A file in this folder has to be a named personal agent — its own computer or persistent runtime, connectors, background work, and approval for sensitive actions — whose main door happens to be a chat client.
