Microsoft Copilot is Microsoft's assistant for individuals and for work. It sits in the Copilot app and inside Microsoft 365 apps, and is aimed at producing finished work from the content and tools a person already uses.

**Runtime:** Desktop, mobile, and web, with voice, keyboard, or pen, as described on the [Copilot product page](https://www.microsoft.com/en-us/copilot). For individuals, that page points at Copilot in the apps you use, including creating and managing email and calendar. At work it is integrated into Word, Excel, PowerPoint, Outlook, and Teams.

**Acts on:** Work content and those Microsoft 365 apps. The same page describes handing multi-step work to Cowork across apps, data, and workflows, and an Autopilot agent that runs in the cloud with its own identity, memory, and tool access, taking action inside guardrails set by the person and the organization.

**Extensions:** Agent Builder in Copilot for work-grounded agents, with Copilot Studio when a team wants to extend them. Organization data connectors are an admin feature of Microsoft 365 and are not cataloged here.

**Notes:** The product page lists Home, where Chat and Cowork sit together, as available in Microsoft Frontier, and lists Autopilot as private preview. Copilot Code on that page is a separate Frontier feature for building apps and is outside this list. This entry is the personal and Microsoft 365 assistant, not GitHub Copilot. Computer-using agents in Copilot Studio are an organization automation tool, not the consumer Copilot app.
